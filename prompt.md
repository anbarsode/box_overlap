To a good approximation, each event's full probability distribution can be broken down into sub-distributions that are blockwise independent from each other, P(theta)=P(theta1, theta2, theta 3)P(theta4,theta4). Nblocks can be fixed at 2, and but number of dimensions per block may need to be tunable (though same for all events once chosen), typically 3 and 2.

Due to the large number of possible pairs, I am approximating each events' each sub-probability distribution by a set of Nboxes (5-1000) disjoint axis aligned bounding boxes.

Different event's Nboxes will differ

The assumption is that the density is uniform within each box. It's value will be given by the box generator.

The Weight function is evaluated at the centre of each box and is provided by the box generator.

- Notice that if you really pick the samples randomly from all, you will get more samples in the denser regions and fewer samples in the rarer regions, in proportion to the probability density there
